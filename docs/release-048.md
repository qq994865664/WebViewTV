# WebView电视 0.4.8

加载过程显示实际阶段与剩余等待时间，失败后提供可直接操作的恢复入口。菜单改用暖炭灰和青绿色，减少遮挡并适配手机触摸与电视遥控。

## 加载与恢复

- 统一状态卡显示连接页面、准备播放器、等待直播画面、调整播放画面等真实阶段；显示来源序号、已等待秒数和切源倒计时。时间条表示等待预算，不虚构视频下载百分比。
- 每个来源按设置等待 5、10、15 或 30 秒，默认 15 秒；同一轮每源只试一次，累计最多 60 秒。全部失败或达到上限后停止等待，提供重试、下一个来源、选择频道。单源频道不显示切源按钮。
- 关闭自动切源时，18 秒后显示手动恢复入口。手动重试或切源开始新一轮；持续真实播放两秒后允许处理后续独立故障，偶发单帧不清空整轮记录。
- 打开频道菜单继续恢复并保留菜单；设置、节目单、失焦和后台暂停计时，返回后继续剩余时间。翻页动画期间暂缓旧源判断。
- 短缓冲延迟一秒提示，恢复后隐藏；超时错误保持稳定，旧页面事件不能重新触发转圈。失败时停止主页面加载并暂停页面视频。
- 换台前五秒的频道名称合并进加载卡；起播后只显示剩余时间的频道信息。频道菜单、信息横幅、加载卡互斥。

## 菜单与操作

- 暖炭灰底色、约 90% 不透明度、青绿色播放标记、白色焦点描边；设置和节目单使用同组颜色。
- 菜单占约 48% 屏宽，分组和频道约 1:3；保留收藏及原分组。当前播放与当前浏览有不同标记，节目简介仅出现在焦点行。
- 手机加大文字与触摸行，电视保留更紧凑的遥控浏览密度。底部三个主入口为收藏、节目单、更多；切源、刷新、画中画移入更多。
- 保留左右返回定位、分组连续滚动和上下翻页手势，不使用实时背景模糊。

## 验证与兼容

测试使用 MuMu Android15。最低 Android9 / API28；沿用正式签名，可覆盖升级并保留设置。通用包支持 ARMv8，另提供字节相同的 ARMv7 下载名称供 32 位电视盒子选择；应用没有原生 `.so` 库。Android9 ARMv7 实机尚未验证。

本次只调整交互、加载恢复和显示，不改变频道数量、EPG 映射或网页直播地址。上游未提供播放地址的频道仍可能无法播放，现在会在时限内提供明确恢复入口。

回归结果：

- 手机布局与电视 UI 配置分别通过 63 项导航、41 项手势断言，包含分组跨屏动画和左右返回位置。电视配置测试仍运行在 MuMu 上，并非真实电视硬件测试。
- 24 项真实 WebView 播放断言：旧画面隔离、首帧/全屏条件、阶段变化不延长时限、失败不闪烁及遥控重试。
- 45 项自动切源断言：单源、多源、禁用、60 秒上限、前后台剩余预算、菜单打开时继续切源。
- 17 项频道信息互斥与五秒显示断言。
- 16 项 JavaScript 播放进展断言、11 项 HLS 恢复断言。
- 配置校验通过：795 个频道条目、984 个来源、265 个 EPG 映射。
- 正式包资源路径和内容校验、API28 的 v3 签名校验通过；MuMu 从 0.4.7 覆盖升级保留配置。已检查真实播放、菜单、更多弹层、广东 4K 超时及遥控重试。

测试入口为 `scripts/test-navigation.ps1` 的 Navigation、Playback、Fallback、Information 四个 Suite，电视布局使用 `-Suite Navigation -TvUi`。测试 APK 使用独立包名，不替换正式应用或其配置。
