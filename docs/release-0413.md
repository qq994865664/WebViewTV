# WebView电视 0.4.13

仅调整频道菜单左侧分组行高，使分组列表比 0.4.12 稍宽松。

分组行高改为 0.4.11 原始高度的 70%，即缩小 30%，比 0.4.12 的 60% 高度增加约 16.7%。文字仍垂直居中，遥控焦点和跨屏滚动继续按实际行高处理。

底部四栏按钮继续使用缩小 50% 的高度；频道信息字号、频道名称与来源同一行布局、长域名省略、右侧节目预览和深蓝配色保留。成功出画后的五秒信息、上下翻页、加载进度与等待反馈、超时自动切源行为沿用 0.4.12。
