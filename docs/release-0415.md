# WebView电视 0.4.15

新增央视网直播时段限制提示，适用于 CCTV8 等使用 tv.cctv.com 的频道来源。

当网页明确显示“由于播出安排变更，暂不支持播放该时段内容”，且没有正常播放的视频时，加载卡改为显示：

> 播出安排变更 · 当前时段暂不支持播放

原有来源域名、源序号和超时倒计时继续显示；按设置的 5/10/15/30 秒切换备用来源，不因提示而重新计时。等待结束时，失败卡和最近失败诊断保留该原因。自动切源关闭时，仍按原有等待上限结束。

只在央视网页出现完整对应文案时识别，容忍提示换行与中英文逗号；不会根据频道名称固定屏蔽 CCTV8，也不会把普通加载失败推断为时段限制。继续支持 0.4.14 的登录限制提示和手机播放兼容恢复。

验证通过 26 项网站兼容 Node 断言、77 项 MuMu Android15 WebView 播放断言。新增集成检查使用本地 HTML 和央视页面基址复现提示，覆盖加载卡文案、失败卡保留、诊断记录、超时不重置及旧标识/错误站点代码隔离。正式构建资源、最低 API28、手机/电视入口及 v3 签名检查通过。

真实 `https://tv.cctv.com/live/cctv8/` 回测亦复现该限制，新版识别并显示对应原因；正式包已在 MuMu 覆盖安装。本版仅明确网站限制提示，不承诺备用来源一定可播放。

版本 0.4.15 / versionCode 23，Android9 及以上，沿用正式签名支持覆盖安装。提供 ARMv8 兼容通用包、字节相同的 ARMv7 盒子包与 SHA-256 校验文件。
