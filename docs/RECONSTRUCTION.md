# 实现范围与重建记录

本工程基于用户提供的 `com.vasthread.webviewtv.apk` 的静态证据和 MuMu Android15 运行观察，编写独立的 Android Java 核心实现。当前版本为 `0.4.10` / versionCode 18，包名 `com.vasthread.webviewtv.reconstructed`；与原应用并存，不宣称恢复了原源码或全部功能。

## 来源与保留署名

Activity、原生菜单、设置、配置仓库、EPG 仓库及构建脚本为本次研究实现。频道和网站适配器 JSON 基于所提供 APK 的 assets 解码结果维护，包含 795 个频道条目、984 个网页来源、37 个分组，原有 32 个网站适配器现增加山西移动端规则至 33 个。内置初始化与可编辑配置修正了原快照中两条海峡卫视 URL 的中文误前缀；原研究目录保留未改动的解码证据。

`app/src/main/assets/js/` 中的 `base.js`、`platform_x5.js`、`main.js`、`remove_controls.js` 保留原 APK 资源及 **vasthread / WebView电视** 署名，所提供 APK 未包含明确覆盖这些打包资源的授权文件，原权利归属不因重建而改变；没有为提取资源另加开源许可证。`tv_fullscreen.js`、`fast_switch.js` 为新增控制器。桥接依据原 APK 的频道、URL、网站适配器与 WebView 代码，当前保留 `main.getWebPageAdapter/getExtra/sendKeyEvent/setVideoSize/reportVideoLoadingState/schemeEnterFullscreen` 等接口行为。

本仓库包含独立构建所需代码和 assets，不依赖本机研究目录。原 APK、完整反编译目录、运行证据、缓存、APK 产物和调试签名私钥未纳入仓库。历史证据保存在本机 `D:\WebViewTV\webviewtv-research\evidence`；原始研究报告与解码结果仍保留在其上级研究工程。此目录结构不同于仓库，历史验证文档中出现的 `reconstructed/`、`reports/`、`evidence/` 均指当时本机研究目录。

## 实现与兼容范围

应用使用 Android 系统 WebView，按网站适配器注入播放器脚本；支持桌面 UA、DOM 全屏、WebChromeClient 网站全屏视图与可选画中画。它没有重建原应用的腾讯 X5/Gecko 内核、所有原设置页面、代理重试、公告或统计 SDK。原 `server_config.json` 保留在本机研究目录；新版工程已移除这份未使用的服务器配置。

原生菜单采用分组与频道双栏、当前频道和收藏标记，支持触摸、遥控焦点及数字选台。ListView 复用频道行；关闭菜单时 WebView 占满播放区。菜单以 720px 屏幕高度等比缩放。WebView 中视频保留原比例，节目比例不同时可出现正常黑边。跨域 iframe 只能控制外层布局，内层播放器由网站控制。

注入脚本缓存于内存，网页与播放回调附带页面标识，丢弃旧页面异步事件。Logcat 标签 `WVTResearch` 记录页面、注入、视频状态和首帧，供复核。来源能否播放仍受网站、网络、地区、登录/DRM、编码支持与自动播放策略影响。

## 版本变化

### 0.4.10：全部频道节目预览、紧凑分组与无提示翻页

频道行固定显示名称及当前节目，焦点切换不改变行高。分组独立行高，滚动定位按实际高度处理。上下手势移除方向和目标频道提示，保留翻页、回弹与一次性请求。详见 [release-0410.md](release-0410.md)。

### 0.4.9：深蓝菜单、起播估算与完整五秒信息

移除菜单顶部区域，设置移入底部四栏工具，缩小手机字号并恢复深蓝配色。加载显示来源域名和受真实阶段约束的估算进度，结合每源八次成功起播耗时中位数；超时倒计时保持独立。频道实际出画后才开始完整五秒信息展示。详见 [release-049.md](release-049.md)。

### 0.4.8：有时限的加载反馈与暖炭灰菜单

新增统一播放状态卡，显示真实连接阶段、等待时间、剩余预算和来源序号；等待条不代表下载百分比。首帧、页面提交及全屏条件全部满足才揭开遮罩。短缓冲延迟一秒提示，失败后固定显示可遥控操作的重试、下一个来源、选择频道。每轮故障最多 60 秒、每源一次；设置、节目单和后台保留剩余计时，浏览频道菜单不暂停恢复。持续真实播放两秒后允许后续独立故障重新尝试，单帧不清空整轮记录。频道信息前五秒合并进加载卡，正常播放仅显示尚余的信息时间。

菜单统一暖炭灰与青绿色，约 90% 不透明度、48% 屏宽，分组与频道约 1:3。白色描边表示焦点、青绿色标记表示播放，节目简介仅在焦点行显示。手机增大文字和触摸行，电视保留适合遥控浏览的密度；底部三个主工具，切源、刷新和画中画收进更多。详见 [release-048.md](release-048.md)。

### 0.4.7：播放隔离、平滑分组与网站兼容修复

换台立即遮住旧 WebView，等新文档提交、真实首帧、全屏布局及视觉状态回调就绪后显示；拖动时隐藏旧信息。分组跨屏逐帧滚动，保留左右往返位置。加载状态使用首帧和时间推进，短暂缓冲防抖，终止错误不再被 play/waiting 事件改回加载。全屏控制支持同域 iframe、已解码但高度为零的视频以及网页缩放和宽度溢出。

杭州生活发生原生 HLS 错误时只恢复一次，使用网页自己的公开播放地址，注入 HLS.js light 1.7.3；第三方库与 Apache-2.0 许可保存在 `assets/vendor/`。山西三个频道优先原有官方移动端来源，桌面地址仍作备用。广东 4K 官方页面未提供播放地址的情况无法仅靠界面修复恢复，现有限等待后提示。详见 [release-047.md](release-047.md)。

### 0.4.6：换台后独立显示五秒频道信息

新增独立的 `ChannelInfoView`，从列表菜单移出频道与节目信息。首次进入播放或切换到不同频道时显示五秒，连续换台重置计时，节目单刷新和同频道切源只更新内容。菜单恢复完整高度，选台时先立即关闭列表，打开菜单、设置、节目单、画中画以及失焦、后台和销毁均隐藏信息。浮层不拦截触摸、不抢遥控焦点；播放恢复后仅清除加载提示，不额外弹出频道操作提示。详见 [release-046.md](release-046.md)。

### 0.4.5：上下翻页与半透明频道菜单

参考原 APK 手势类 `p090.C1128` 的整页跟手位移与 240ms 滑出动作，独立实现双向翻页：旧页退出后请求频道，新页从相反边缘进入。原版 `C1127` 使用缩放淡入，新版按本次需求改为纵向进入；不宣称逐帧复刻。连续拖动先完成已提交的前一次换台，面板、失焦等重置会撤销尚未执行的回调。翻页期间暂停旧源的超时判断。

频道菜单和底部居中的频道信息浮层采用约 80% 不透明度的深色背景，文字与焦点保持清晰；信息浮层位于菜单下方，互不遮挡。移除合成的「全部频道」入口，打开菜单定位播放频道所属分组，保留已有的左右焦点与滚动位置修复。详见 [release-045.md](release-045.md)。

### 0.4.4：可配置超时自动切源

增加 `playback.sourceTimeoutSeconds`，支持关闭（0）和 5、10、15、30 秒，默认 15 秒。通过首帧和带页面 token 的视频时间推进信号判断起播及持续播放；加载失败或持续无进展达到时限后，依次尝试未试过的来源。全部失败后停止，单源只提示；手动换台、切源和刷新重新开始一轮，实际播放恢复后可处理后续独立故障。面板、失焦和后台暂停计时，恢复后重新给予等待时间。设置保存、JSON 导入及验证脚本同步支持该字段，远程频道更新继续保留本机播放设置。测试详见 [release-044.md](release-044.md)。

### 0.4.3：上下换台跟手动画

WebView 和网页自定义全屏视图放入独立播放容器，上下滑动时小幅跟手位移；原生浮层提示目标频道及是否可松手切换。松手后立即请求频道，260ms 缓出归位和渐隐；短滑取消以 180ms 回弹。新拖动取消旧动画，打开菜单、普通选台、窗口失焦、暂停和方向变化均清理动画及手势状态。拖动期间只在提示变化时更新文字，避免重复布局；系统关闭动画时直接切换。详见 [release-043.md](release-043.md)。

### 0.4.2：播放画面滑动手势

新增原生 `PlayerControlsView`，上滑下一个频道、下滑上一个频道，左滑下一个直播源、右滑上一个直播源。手势仅作用于播放画面，复用现有播放和全屏逻辑；轻点和遥控操作继续保留。单指松手后按距离及主方向判断，每次最多触发一次，过滤短滑、歧义斜滑、多指、取消事件和长按误点击。单直播源提示而不重新加载，菜单、设置、节目单和画中画不接受播放手势。见 [release-042.md](release-042.md)。

### 0.4.1：左右列表焦点切换保持位置

返回左栏时保留当前分组的原始屏幕位置，进入右栏时保留频道选中项和滚动位置。分组高亮和收藏计数改为更新可见行，避免整表刷新。触摸模式恢复和下一帧定位使用请求序号，新的按键、触摸、筛选或关闭操作会取消过期恢复。实际更换分组仍更新频道列表，重新打开菜单仍定位正在播放的频道。MuMu Android15 上的独立仪器测试通过 56 项位置和筛选断言，正式 APK 覆盖安装后完成真实频道左右切换验证，详见 [release-041.md](release-041.md)。

### 0.1.1：修复持续提示 JS 注入失败

Windows aapt2 的 `-A` 曾将嵌套资源写成 `assets/js\base.js`，Android 按 `js/base.js` 读取时失败，进度回调又重复重试。离线构建改用 JDK jar 写入资产，通过 `verify-assets.ps1` 检查 ZIP 正斜杠路径与所有资源 SHA-256。注入结果通过 JS 回调确认，每页失败只提示一次，详细错误进入日志。

### 0.2.0：电视菜单与自动全屏

新增深蓝双栏菜单与遥控焦点处理；选台、切源、刷新统一收起菜单并进入全屏。`tv_fullscreen.js` 复用网站播放器 DOM，解除祖先变换、裁切与滚动限制，不重建播放器。可视区使用 `documentElement.clientWidth/clientHeight`，兼容部分站点的 HTML 缩放。冷启动恢复、数字选台、收藏和切源在 MuMu 上进行观察验证。

### 0.3.0：设置、频道配置、EPG 与快速切台

设置集中提供频道编辑、UTF-8 JSON 导入导出、缓存周期、EPG 与播放选项；Android15 使用系统文件选择器。无效导入或下载保留现有配置，原子写入并保留有效备份。播放画面按返回显示退出确认，退出后停止播放并移除任务；面板内返回先关闭面板。

EPG 使用用户指定的 [FreeEPG 中国源](https://free-epg.de/countries/cn)。原 795 条记录中，265 条有明确映射，涉及 212 个名称；未把节目源中的其他频道添加到列表。获取与 XMLTV 流式解析在后台执行，只缓存已匹配频道以及过去 48 小时至未来 8 天的节目。无时区信息按北京时间；节目缺失或空档显示暂无，不生成节目内容。映射审计见 [free-epg-mapping.md](free-epg-mapping.md)。

快速切台使用较早的安全注入、150ms 初期扫描、成功来源记忆、UA 复用与相邻站点连接提示；稳定播放后扫描降为 1500ms，不后台预播。真实首帧优先采用 `requestVideoFrameCallback`；旧 WebView 可回退为经过播放状态检查的 `playing-fallback`，不把元数据加载视为首帧。MuMu 的 12 次有效样本平均首帧从 2543.0ms 降至 2298.3ms，网络与样本限制见 [features-03-validation.md](features-03-validation.md)。该报告的 APK 哈希与版本均属于 0.3.0。

### 0.3.1：使用 GitHub 维护频道

默认频道源改为 `https://raw.githubusercontent.com/qq994865664/WebViewTV/main/config/tv-config.json`，默认周期 24 小时。更新只合并 `channels`，不覆盖本机 EPG、播放与缓存周期。GitHub main 分支提交后，应用下次到期或设置中手动更新时读取新列表；运行期间每分钟检查，关闭期间不唤醒设备。

默认 raw 地址读取失败时，自动尝试同一仓库的官方 Contents API：`https://api.github.com/repos/qq994865664/WebViewTV/contents/config/tv-config.json?ref=main`。使用 `Accept: application/vnd.github.raw+json` 直接读取文件内容，公开仓库无需 token，依据 [GitHub 官方 Contents API 文档](https://docs.github.com/en/rest/repos/contents#get-repository-content)。缓存记录成功入口，下次优先读取该入口；ETag/Last-Modified 仅发送给原成功入口，跨入口时完整重取。两个入口都失败时保留现有列表，不改用户配置中的 raw 地址。

旧安装中的空源地址进行一次升级迁移，已有非空自定义地址保持。迁移后主动清空仍能停用远程更新。持续频道维护应修改仓库；本机编辑在以后远程更新时会被仓库内容覆盖。

工程资产直接包含于仓库，PowerShell 构建支持 `-Sdk`、`-Jdk` 及 `ANDROID_HOME`、`JAVA_HOME`。配置提交前可运行根目录 `scripts/validate-config.py`；所有字段与手工维护方式见 [配置说明](../config/CONFIG.md)。
