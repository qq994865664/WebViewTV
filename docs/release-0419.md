# WebView电视 0.4.19

广东组现有「广东经济科教」频道增加第 2 个来源 [最爱TV](https://zuiai.tv/i/1453)，保留原来源和 EPG 映射，不新增重复频道。仓库配置与安装包内置配置同步更新。

## 自动播放适配

该页面的实际播放器位于 `iframe#vlive` 指向的 `so.zuiai.tv` 页面，外层脚本无法跨域控制内部视频。新增适配读取页面提供的播放器地址，在同一 WebView 中打开，随后由既有视频控制器执行播放、全屏和实际播放进度检测。保留网站提供的完整地址，不把视频流地址固化在配置中。

跳转仅作用于 `zuiai.tv/i/1453`，目标限制为 HTTPS 的 `so.zuiai.tv/m3u8/live/` 或 `/m3u8/` 播放页。查找有次数上限；换台和页面关闭取消旧回调。沿用用户设置的超时预算，不因跳转重置计时。频道信息与来源记忆仍显示和保存原始最爱TV链接。
