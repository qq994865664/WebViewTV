# WebView电视 0.4.7

修复切台残留、分组跨屏跳动、加载闪烁及部分网站无法全屏的问题。

## 行为修复

- 换台立即遮住旧视频，等新网页提交、真实首帧、全屏布局和视觉状态回调完成后再显示。上下拖动时隐藏旧频道信息和加载提示，旧页面回调不能揭开新频道的遮罩。
- 遥控器移动到屏幕外的分组时逐帧滚动，连续按键可从当前滚动位置继续；左右返回保留原有焦点与位置。
- 不再把 `play` / `canplay` 当作已经出画。短暂缓冲延迟显示，超时或加载失败后显示稳定错误，不被反复到来的播放事件改回转圈。关闭自动切源时，首次起播仍在 18 秒后结束等待提示；启用时遵循 5 / 10 / 15 / 30 秒配置。
- 全屏选择实际视频，处理已解码但高度为零的播放器、祖先缩放、页面宽度溢出和同域 iframe。视频保持原比例，节目自身比例不同时仍保留合理黑边。
- 杭州生活使用的旧网页播放器在 MuMu 原生 HLS 路径报错后不断重载。现在仅对葫芦网启用一次 HLS.js 兼容恢复，沿用网页提供的完整地址，离开页面销毁；失败仍交给原有超时切源，避免无限重试。内置 HLS.js light 1.7.3，保留 Apache-2.0 许可。

## 回归验证

- 20 项真实 WebView 播放断言：旧页面隔离、首帧判断、失败后不闪烁、短缓冲防抖、缩放/零高度/超宽布局及同域 iframe 全屏。
- 61 项导航、41 项手势与翻页断言。
- 40 项自动切源断言、17 项频道信息互斥与 5 秒显示断言。
- 16 项播放进展断言、11 项 HLS 恢复断言（站点范围、健康播放器保留、一次恢复、失败停止、页面离开销毁）。
- 配置校验：795 个频道条目、984 个来源、265 个 EPG 映射。
- APK assets 路径与内容校验通过，Android9+ 正式签名验证通过。运行测试使用 MuMu Android15，未新增 Android9 / ARMv8 真机验证。

