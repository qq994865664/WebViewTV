# WebView电视 0.4.12

进一步压缩频道菜单的分组与工具区域，放大换台后的频道信息文字，并统一频道信息、加载和失败卡的来源布局。

## 菜单与频道信息

- 左侧分组行高在 0.4.11 基础上缩小 40%，为原高度的 60%；分组名称继续垂直居中，焦点与滚动按实际行高处理。
- 底部“设置／收藏／节目单／更多”四栏按钮高度缩小 50%，继续等宽。右侧频道行保留频道名称和当前节目的固定两行预览。
- 频道信息参考字号调整为：频道名称 25、来源域名与来源序号 17、当前节目 16、下一节目 15，随横屏尺寸等比适配，面板高度随文字内容调整。
- 频道名称位于头部左侧，域名与 `源 1/2` 组成右侧区域，并与频道名称同一行垂直居中。较长域名在末尾省略，保留完整的来源计数；完整网址继续通过来源详情查看。
- 加载与失败卡使用同样的头部布局，保留原有加载字号和恢复操作。

## 保留的观看行为

继续使用深蓝半透明配色。频道成功出画并完成翻页后，信息面板完整显示五秒再淡出；节目单刷新不重新计时，菜单、设置、节目单和手势过程继续与信息面板互斥。

加载进度沿用 0.4.11 的真实状态优先方案：连续约三秒没有新进展时隐藏百分比，使用等待文案及流动进度条；播放中的停顿单独显示缓冲状态。来源倒计时继续遵循设置，估算及布局更新不延长来源超时。自动切源、列表定位和上下翻页逻辑保留。
