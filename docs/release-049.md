# WebView电视 0.4.9

恢复深蓝配色，精简菜单和加载信息，并修复慢加载后频道信息一闪即逝的问题。

## 界面与操作

- 菜单、加载卡、频道信息、设置和节目单统一使用深海军蓝、蓝灰辅助文字与浅蓝焦点。菜单约 90% 不透明度。
- 移除菜单顶部图标、标题、频道总数和关闭按钮。保留分组标题，列表获得更多纵向空间。
- 底部四栏等宽：设置、收藏、节目单、更多。更多提供切换直播源、刷新、画中画和来源详情，后者可查看完整的配置网址。
- 手机菜单文字比 0.4.8 缩小约 20%，保留触摸区域；电视保留原有阅读密度。长名称在遥控焦点停留时滚动。
- 返回键或点击菜单外的播放区域关闭菜单，点击菜单内部空白不关闭；选择频道自动收起。遥控器从工具栏返回原来的列表区域并保留位置。

## 加载与来源

加载卡仅保留频道名称、来源域名及序号、`正在加载...X%`、剩余等待或自动切源倒计时。失败后保留来源和简短原因，并提供恢复按钮。域名提取自当前所选频道网页地址，表示来源网站，不冒充实际视频 CDN 地址。

百分比是起播准备程度的估算，不是已下载视频字节比例，也不是超时进度：

- 网页实际进度占 0–30%；网页完成不表示视频可播放。
- 检测到视频元素后进入 30–59%，视频元数据进入 60–74%，当前帧数据进入 75–89%，当前位置至少有 0.5 秒缓冲进入 90–95%。
- 每个来源在本机记录最近八次成功出画耗时，取中位数，在已经确认的阶段内平滑估算。没有历史时仅按真实阶段推进；暂停时间不计入样本。
- 未确认下一阶段时不越过该阶段上限，不因单纯等待而涨到 95%。无法读取视频状态时停留在最后可确认阶段。实际出画且全屏布局完成后立即收起加载框，不为了显示 100% 延迟播放。
- 旧页面事件不更新当前来源的估算。来源切换后重新计算，各来源的历史互相独立。

切源计时与百分比独立，继续遵循设置中的 5、10、15 或 30 秒。文案统一为“X 秒后自动切换直播源”。无备用源、关闭自动切源或整轮剩余时间不足以继续切源时，显示“剩余等待 X 秒”。保留每轮 60 秒上限及关闭自动切源时的 18 秒等待上限。

## 频道信息

频道实际出画后约 200 毫秒显示底部信息，150 毫秒淡入，完整停留五秒，再以 250 毫秒淡出。加载所耗时间不再扣减展示时间。包含频道、来源域名、来源序号和已有节目单，无节目时不占用空白行。

快速连续换台取消旧的显示任务；加载中的自动切源只在最终成功时显示一次；普通缓冲恢复不重复弹出。菜单、设置、节目单和失焦会取消显示，关闭面板不重新弹出；节目单更新不延长计时。

## 兼容

版本 0.4.9 / versionCode 17，最低 Android9 / API28。沿用正式签名，可覆盖升级并保留配置。通用包支持 ARMv8，另提供字节相同的 ARMv7 盒子下载名称；应用无原生 `.so` 库。运行验证使用 MuMu Android15，尚未在 Android9 ARMv7 实机验证。

频道网址与 EPG 映射不变。来源网站本身不可用时，界面改进不会恢复上游直播服务。

- 构建使用全新 class 输出目录，避免被移除的旧匿名类进入发布包；assets 路径、内容与 API28 正式 v3 签名校验通过。
