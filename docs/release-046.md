# WebView电视 0.4.6

频道信息与频道列表分开显示，避免一起占用播放画面。

## 观看行为

- 首次播放或切换到不同频道后，在屏幕底部居中显示频道名称、当前直播源和节目信息，**5 秒后自动隐藏**。计时从请求播放该频道开始，不依赖网页加载速度。
- 列表选台时先关闭菜单再显示信息，两者不同时出现。频道列表恢复完整高度。
- 连续换台从最后一次换台重新计时；旧计时不会提前关闭新提示。
- 同频道切源、自动切源及后台节目单刷新仅更新内容，不重新弹出或延长提示。
- 打开菜单、设置、节目单、画中画，或应用失焦、进入后台时立即隐藏提示；回到播放画面不会重放旧提示。
- 提示不拦截手势、不抢遥控焦点。正常开始播放后清除加载提示，不再额外弹出「确定打开频道菜单」。
- 保留半透明背景、上下翻页、分组定位及已有自动切源设置。
