# WebView电视 0.4.21

左侧频道分组行高在 0.4.20 的最终计算高度上增加 20%（像素取整），手机与电视布局都生效。右侧频道行、字号和底部按钮尺寸不变。

## 广东组 IPTV345 来源适配

适配广东珠江与广东体育的 `iptv345.com` 来源。网页自带多条播放线路；观察到的 `startPlayer()` 设置启动超时后，调用的 `playFLV()/playM3U8()` 又执行 `resetPlayer()`，清掉了刚设置的超时。某条线路不出数据时，网页可能停留在等待中。

新增独立且有上限的起播恢复：五秒内没有视频时钟推进，调用网站自己的线路选择函数尝试下一条未试过的线路；不解析或固化流地址，不重复尝试同一线路。有真实播放进度后停止恢复；换台、页面关闭以及 App 的最终超时都会停止旧尝试。网站内部线路尝试不增加 App 直播源的等待预算，仍遵循设置中的 5/10/15/30 秒（关闭自动切源时 18 秒）规则。

新增播放器规则只选择 `video#vstPlayer`，避免误选其他视频。恢复逻辑限于广东珠江（id=5）与广东体育（id=4）；诊断新增 `media.iptv` 的阶段、网站内部线路序号和尝试次数。

## 证据与限制

- 外层页面和播放器脚本均可加载。网页计时器被重置清除属于已确认缺陷；用户手机、盒子具体失败原因仍需结合设备日志，不能等同于已确认由这一缺陷导致。
