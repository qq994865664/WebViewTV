# WebView电视 0.4.10

恢复频道列表中所有频道的当前节目预览，压缩左侧分组高度，并简化滑动换台时的画面。

## 菜单

- 右侧频道固定两行显示：频道名称与当前节目。未选中频道也能预览节目；缺少数据或关闭 EPG 时显示“暂无节目单”，不增加频道或额外映射。
- 焦点只改变背景与文字滚动状态，不改变节目可见性或频道行高。长节目名称正常显示省略号，获得遥控焦点后滚动显示。
- 左侧分组独立使用单行高度：电视参考行高由 56 缩至 40，约减少 29%；手机保留至少 40dp 触摸高度，右侧频道行高不变。
- 分组动画与快速按键中断按实际分组行高定位，保留左右返回时的选中项及滚动位置。

## 换台手势

上下滑动时移除“上一个频道／下一个频道”、目标频道、“松手切换／继续滑动”等提示框。保留播放画面的跟手翻页、上下双向进入、短滑回弹以及连续手势的一次性换台逻辑。

换台请求提交后，继续使用精简加载框；实际出画后显示包含来源信息的五秒频道浮框。菜单、加载、计时和深蓝配色沿用 0.4.9。

拖动、回弹和翻页期间暂停旧源计时并隐藏加载卡。拖动开始取消旧的延迟信息任务；新频道提前出画时，信息等待翻页结束再显示，避免浮框覆盖动画。

## 安装

版本 0.4.10 / versionCode 18，最低 Android9（API28），正式签名支持覆盖升级并保留配置。发布通用 ARMv8 兼容 APK 与字节相同的 ARMv7 盒子下载包，应用没有原生 `.so` 库。

运行验证使用 MuMu Android15；电视 UI 配置测试仍在模拟器上，Android9 ARMv7 盒子实机尚未验证。频道网址和 EPG 数据源不变。
