# WebView电视 0.4.3

为上下滑动换台增加跟手动画，缓和切换时的突然变化。

- 画面随手指轻移，中央卡片显示将要切换的频道名称。
- 达到换台距离时提示「松开切换频道」；距离不足时提示继续滑动。
- 短滑取消以 180ms 缓出归位；确认换台后，画面和提示在 260ms 内归位、渐隐。时长会跟随系统动画缩放。
- 松手时立即调用频道播放逻辑，不等待动画结束。频道网络加载所需时间仍取决于来源。
- 反向滑动或新一轮拖动会接管旧动画；打开菜单、普通选台、切到后台、窗口失焦和方向变化会清理位移。
- 系统禁用动画时直接切换；左右切源和轻点菜单操作保留。

实现使用原生容器位移、透明度动画和文字卡片。WebView 与网页自定义全屏内容共用播放容器，控制层和面板保持原位。拖动不捕获视频截图；提示未变化时不重新设置文字，减少拖动过程的布局工作。
