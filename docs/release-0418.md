# WebView电视 0.4.18

设置菜单新增「版本更新」：显示当前版本，点击「检查更新」查询本仓库最新正式 Release；发现更高版本时，显示版本号和「浏览器下载新版」按钮。

- 检查在后台执行，检查期间禁用重复请求，区分无更新、网络失败、超时与服务限流。关闭设置后完成的检查不会重新打开面板。
- 按三段数字比较版本，避免把 0.4.9 判断为高于 0.4.18，忽略测试版和草稿，不提供降级。
- ARMv7 设备优先下载 ARMv7 包，缺少时使用通用包；ARM64 和其他架构选择通用包。无适合的完整安装包时，按钮明确改为查看该版本发布页。
- 优先调用系统默认浏览器打开 GitHub 的 APK 下载地址，未设置默认浏览器时由系统处理选择；缺少浏览器时给出提示。App 不自行下载、安装或申请安装权限。
- 检查及浏览器跳转保留未保存的设置。应用启动和观看直播时不自动检查或弹窗。
- 保留 0.4.17 的盒子等待计时修复和现有频道、EPG、手势与菜单行为。
