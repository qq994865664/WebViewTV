# WebView电视 0.4.5

## 界面与操作

- 上下滑动采用完整翻页：播放画面随手指上下移动，松手确认后旧页滑出，下一页从相反边缘进入。上滑下一个频道，下滑上一个频道，短滑回弹；左右切源不变。
- 参考原 APK `ChannelPlayerView → p090.C1128/C1127` 的静态证据：整页位移、240ms 退出。原版进入采用缩放淡入；本版改为 240ms 纵向进入以形成连续翻页，并非逐帧复刻。
- 旧页退出后请求新频道，新增等待约 240ms，受系统动画倍率影响；新页进入与网页加载并行。系统关闭动画时立即请求频道。只保留一个 WebView，不复制视频帧、不预载多个播放器。
- 快速连续滑动会先完成前一笔已提交的换台。打开菜单、窗口失焦和生命周期重置会清除动画及尚未执行的换台回调，防止菜单打开后突然换台。翻页期间延后旧源超时检测。
- 当前频道、直播源和正在播出／接下来节目信息独立为屏幕底部居中的圆角浮层，与频道菜单保持间距。随频道菜单打开与关闭，不遮挡列表和工具按钮。
- 菜单与信息浮层背景约 80% 不透明度，播放画面仍可透出；文字与遥控焦点保持清晰。整体背景仅轻度压暗。
- 移除合成的「全部频道」入口，保留收藏和配置中的分组。打开菜单定位当前频道所属分组；若收藏中已包含该频道则保留收藏分组。不修改频道配置或 EPG 映射。
