# WebView电视 0.4.2

新增安卓播放画面的单指滑动手势。

| 手势 | 操作 |
| --- | --- |
| 上滑 | 下一个频道 |
| 下滑 | 上一个频道 |
| 左滑 | 下一个直播源 |
| 右滑 | 上一个直播源 |
| 轻点 | 打开频道菜单 |

频道和直播源首尾循环。切换后继续全屏播放，保留原有来源记忆和快速切台逻辑。只有一个直播源时，提示「当前频道仅有一个直播源」，不重新加载。

手势在单指松手后判定，每次最多切换一次。位移至少 48dp（且不低于两倍系统触摸容差），主方向位移超过另一方向的 1.4 倍；短滑、歧义斜滑、多指、取消事件不触发切换。拖动后回到起点和长按不误触菜单。慢速滑动也可使用，不要求快速甩动。

手势仅在原生播放操作层生效。菜单、设置、节目单内继续滚动当前面板；画中画不处理播放手势。遥控器方向键的既有行为保留。

## 验证

2026-10-13，MuMu Android15：

- 使用生产代码的 Android 仪器测试通过 **56 项列表导航断言、20 项手势断言**。覆盖四向、快慢滑动、轻点、短滑、斜滑、松手前不触发、单次触发、返回起点、取消、多指、窗口失焦、面板遮挡和恢复。
- 正式 APK 覆盖安装后，实际滑动确认频道 51 → 52 → 51，频道 51 的来源 1 → 2 → 1；各手势对应一次 `play` 日志。
- 单直播源的频道 50 左滑显示提示，无新的 `play` 日志。
- 轻点打开菜单；频道列表、设置、节目单可滚动，测试期间没有触发换台或切源。当前配置保留 795 个频道、1 个收藏和 3 天频道缓存。
- 沿用正式发布证书，APK 资产路径和内容校验、签名校验通过。兼容最低 Android9；本次运行实测为 MuMu Android15，未新增 ARMv8 真机或 Android9 实机测试。

回归命令与依赖同 [0.4.1](release-041.md)：`scripts/test-navigation.ps1`。本次新增 `tests/navigation/GestureChecks.java`；独立测试包使用虚构频道，不读写正式应用数据，测试后已卸载。
