# WebView电视 0.4.20

Android 应用包名从 `com.vasthread.webviewtv.reconstructed` 更改为 **`com.webviewtv.app`**，去掉包名中的 `vasthread`。同步修改 Java 命名空间及源码目录、Gradle namespace/applicationId、Manifest、测试包与运行脚本。桌面名称仍为「WebView电视」，保留图标、频道与播放器功能。

## 安装与配置迁移

这是新包名应用，不能覆盖安装旧包名版本，Android 会同时保留两个应用。包名变化会隔离应用私有数据，旧版收藏、观看位置、缓存及设置不会自动转入新版。

1. 在旧版「设置 → 频道列表 → 导出配置」，将 JSON 保存到下载目录等可共享位置。
2. 安装新版，在「设置 → 频道列表 → 导入配置」选择刚导出的 JSON，迁移频道、播放和 EPG 配置。
3. 收藏与上次观看频道不在该 JSON 中，需要重新设置。确认新版配置正确后，再自行卸载旧版；本次不会自动卸载或清理旧版。

默认使用仓库频道列表的用户，新版仍能从同一仓库更新频道。旧版的检查更新入口可以下载此次 APK，但安装后会新增一个应用；后续 `com.webviewtv.app` 的同包名版本可正常覆盖升级。

原始资源的作者署名、历史发布说明及研究证据中的原包名保持原有含义，本次只迁移应用身份，不改写来源记录。

版本 0.4.20 / versionCode 28，最低 Android9，继续提供 ARMv7 盒子包和手机通用包。
